# 幽读 — 应用商店简介

## 一句话描述

纯本地电子书阅读器，支持 TXT/EPUB/MOBI/PDF/CBZ/CBR 格式，含 RSS 订阅和 OPDS 书库浏览（可选联网功能）。

## 详细介绍

幽读是一款本地优先的电子书阅读器：核心阅读功能完全离线可用，无需登录、无云端依赖，所有数据存储在本地设备；RSS 订阅与 OPDS 书库为可选联网功能，仅在用户主动添加源时访问对应网址。

### 核心功能

**📚 本地书库管理**

- 支持 TXT、EPUB、MOBI、AZW3、PDF、CBZ、CBR、ZIP、RAR 等主流电子书格式
- 自动识别书籍类型：小说（纯文字）、图文（文字+插图）、漫画（纯图片）
- 批量导入，自动提取封面、目录、元数据
- 书架分组管理，支持评分和阅读状态标记

**📖 阅读体验**

- 三种阅读模式：按章显示、无限拼接、翻页
- 多主题：日间、夜间、护眼、墨绿等
- 自定义字体、字号、行距、页边距
- 繁简转换、智能排版
- 精确阅读进度保存（段落级）
- 书签和高亮标记
- 全文搜索

**📰 RSS 订阅**

- 支持 RSS 2.0 和 Atom 格式
- 自动抓取全文内容
- 定时检查更新

**🌐 OPDS 书库**

- 浏览在线 OPDS 书库
- 一键下载导入

### 格式支持

| 格式      | 说明                  |
| --------- | --------------------- |
| TXT       | 纯文本，自动检测编码  |
| EPUB      | 电子书标准格式        |
| MOBI/AZW3 | Kindle 格式           |
| PDF       | 含扫描版 PDF 图片渲染 |
| CBZ/CBR   | 漫画格式              |
| ZIP/RAR   | 压缩包图片            |

### 隐私说明

- 核心阅读功能完全离线可用，不收集任何用户数据
- RSS 订阅与 OPDS 书库为可选联网功能，仅在用户主动添加源时访问对应网址
- 所有书籍和阅读数据存储在本地设备

### 系统要求

- Linux x64（Deepin 20/23/25、Ubuntu 20.04+、Debian 11+）
- 依赖：GTK3、NSS、libgbm（安装时自动处理）
